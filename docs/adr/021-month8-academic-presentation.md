# ADR-021: Month 8 Rescoped - Academic Presentation & Review Month

## Status: Accepted | Month 8 open

## Context
User directive (repeated, absolute): NO superhuman features. The sole
goal is preparing the project for presentation to cognitive
neuroscience, cognitive psychology, and neuropsychology professors.
The old Month 8 plan (API server, 3D anatomy, deployment matrix) is
SUPERSEDED. ADR-006 + ADR-020 + this ADR together end the superhuman
track for this phase.

## Decision - Month 8 = three deliverables for academic review
1. W29: Presentation package - a 15-slide deck built from the 7 paper
   figures, the neuroscience mapping table, and the ADR decision
   lineage (each mechanism claimed with its citation).
2. W30: Live demo script - a 10-minute scripted demonstration:
   emotion monitor (struggle vs reward), Cocktail Party arbitration,
   habit dissociation, somatic avoidance, navigation trajectory,
   EEG spectrum (rest vs threat), and the language narration window
   (ADR-018 boundary shown live). Every beat deterministic (seeds),
   every beat pre-verified by a test.
3. W31-32: Anticipated-questions dossier - a document answering, with
   evidence from the repo, the ten hardest questions a
   cognitive-neuroscience/psychology/neuropsychology professor will
   ask (see gate below for question 1). Plus arXiv skeleton review
   against the professor feedback loop.

## Explicitly deferred (post-review, not cut)
API server, CLI service, 3D anatomy layer, Pi profile, v1.0 release
- all Phase-2 items, scoped by a future ADR after academic feedback.
